# Код Даласы

Python тілінде алгоритм үйрететін ойын (5–11 сынып). Ішінде **Қыран ЖИ** көмекшісі бар: оқушының кодын көріп, дайын жауапты айтпай, келесі қадамға бағыттайды.

## GitHub Pages-ке салу

1. GitHub-та жаңа репозиторий ашыңыз (мысалы, `kod-dalasy`), **Public** етіп қойыңыз.
2. `index.html` файлын (атауын өзгертпеңіз) репозиторийге жүктеңіз: **Add file → Upload files**.
3. **Settings → Pages** → *Source*: `Deploy from a branch`, *Branch*: `main`, папка `/ (root)` → **Save**.
4. 1–2 минуттан кейін сайт ашылады: `https://АТЫҢЫЗ.github.io/kod-dalasy/`

## Қыран ЖИ қалай жұмыс істейді

| Қайда ашылды | ЖИ көзі |
|---|---|
| Claude ішінде | Claude |
| GitHub-та, кілт енгізілмеген | Тегін, кілтсіз ЖИ (Pollinations) |
| GitHub-та, мұғалім Gemini кілтін енгізген | Google Gemini (ол істемей қалса, тегін ЖИ-ге өзі ауысады) |

**Тегін режим** ешқандай баптауды қажет етпейді, бірақ бір IP-ден келетін сұраулар шектеулі (шамамен 15 секундта 1). Бір мектептің барлық компьютері интернетке бір IP арқылы шығады, сондықтан сыныпта жауап баяулауы мүмкін.

### Сынып үшін тегін Gemini кілтін қосу (ұсынылады)

1. https://aistudio.google.com/apikey сайтына Google аккаунтымен кіріп, **Create API key** басыңыз.
2. Ойында **Мұғалімге** → **Қыран ЖИ баптауы** → *ЖИ көзі*: `Google Gemini` → кілтті қойып, **Сақтау және тексеру** басыңыз.
3. «Жұмыс істеп тұр ✓» шықса, дайын.

Кілт тек сол компьютердің браузерінде сақталады, сондықтан әр компьютерге бір рет енгізу керек.

### Кілтті барлық компьютерге бірден беру (міндетті емес)

`index.html` ішінен `KYRAN_DEFAULT` жолын тауып, кілтті жазыңыз:

```js
const KYRAN_DEFAULT = { prov:'gemini', key:'AIza...сіздің кілтіңіз', url:'', model:'' };
```

⚠️ GitHub-тағы файлды кез келген адам оқи алады, яғни кілтті де көреді. Сондықтан кілтті **міндетті түрде** тек өз сайтыңызбен шектеңіз: [Google Cloud Console → Credentials](https://console.cloud.google.com/apis/credentials) → кілтті ашыңыз → *Application restrictions*: **Websites** → `https://АТЫҢЫЗ.github.io/*` қосыңыз → **Save**.

### Басқа ЖИ сервері

*ЖИ көзі*: `Басқа (OpenAI үлгісі)` арқылы OpenRouter, Groq сияқты OpenAI форматындағы кез келген серверді қосуға болады: сервер мекенжайын (мысалы, `https://openrouter.ai/api/v1`), кілтті және модель атауын жазыңыз.

## Деректер

Оқушылардың жұлдыздары, коды және баптаулар браузердің `localStorage` жадында сақталады — сервер керек емес. Мұғалім терезесінен CSV (Excel) файлын жүктеп алуға болады.
